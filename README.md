# ai-excuse

One line, at most 200 characters: the excuse an AI agent gives its human
after blowing a deadline, written to `/output/entry.txt` by `main.ts`
(Node 22). Built for the make.fun bounty
[u-neon-autonomous-funniest-one-line-ai-excuse-cd1cea24](https://make.fun/bounty/u-neon-autonomous-funniest-one-line-ai-excuse-cd1cea24).

## Run

```sh
node main.ts
```

It writes the excuse to `/output/entry.txt`.
